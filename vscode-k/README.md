# K Language for VS Code

Official syntax highlighting, snippets, bracket matching, comment toggling, and file icons for the **K** programming language (`.k`, `.kl`).

## Features
- Syntax highlighting for K keywords (`init::exec`, `ifd`, `>>do`, `def`, `mut`, `pub`, `safe::print`, `list::enum`, `class`, etc.)
- Comment toggling (`;;` line comments, `;* ... *;` block comments)
- Code snippets (`kmain`, `kfn`, `kifd`, `kfor`, `kclass`, `kenum`)
- Custom file icons for `.k` and `.kl`
